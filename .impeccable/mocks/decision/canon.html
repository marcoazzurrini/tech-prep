Longest Substring Without Repeating Characters

MediumReview
2 concepts · revealed when you finish

Given a string s, return the length of the longest substring (contiguous) that contains no repeated character.

Example 1

Input:  s = "abcabcbb"
Output: 3
Why:    "abc"

Example 2

Input:  s = "bbbbb"
Output: 1

Example 3

Input:  s = "pwwkew"
Output: 3
Why:    "wke"; "pwke" is a subsequence, not a substring
