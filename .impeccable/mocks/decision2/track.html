Step 1 · Explanation

What a Set keeps

A Set stores each value once. Adding a value it already has does nothing. It checks "already has" with a rule called SameValueZero.

const tags = new Set(["ts", "js", "ts"]);
tags.size; // 2
Step 2 · Predict the outputOpened by the tutor
const s = new Set([1, "1", NaN, NaN, {}, {}]);
console.log(s.size);
4
Not quite. It prints 5.

Two NaN values count as equal, so they collapse to one.

But two {} are two separate objects. They only match if they are the same object.
