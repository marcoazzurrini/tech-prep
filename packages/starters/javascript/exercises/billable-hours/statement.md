# Billable Hours (easy)

A car park rounds each stay up to whole hours, and bills at least `minimum` hours for it.

`billableHours(stays, minimum)` takes the length of each stay in hours. It should return the hours billed for each stay. The code below throws. Fix it.

Example 1: billableHours([1, 5, 2], 3)  ->  [3, 5, 3]
Example 2: billableHours([0.5, 2.2], 1)  ->  [1, 3]
Example 3: billableHours([], 2)  ->  []
