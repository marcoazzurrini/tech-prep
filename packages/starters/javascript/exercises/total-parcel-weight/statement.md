# Total Parcel Weight (medium)

`totalWeight(ids)` should return a promise of the total weight of the parcels. `weigh(id)` gives a promise of one parcel's weight.

With two parcels or more, the code below gives text instead of a number. Fix it.

Example 1: totalWeight(["p1", "p2"])  ->  7
Example 2: totalWeight([])  ->  0
