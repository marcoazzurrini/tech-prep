# Fill Empty Slots (easy)

Write `fillHoles(list, value)`. It returns a new array with the same length as `list`. Each hole in `list` becomes `value`. Every other item stays as it is, `undefined` included.

Do not change `list`.

Example 1: fillHoles([1, , 3], 0)  ->  [1, 0, 3]
Example 2: fillHoles(new Array(2), "x")  ->  ["x", "x"]
Example 3: fillHoles([undefined, , 5], 0)  ->  [undefined, 0, 5]
