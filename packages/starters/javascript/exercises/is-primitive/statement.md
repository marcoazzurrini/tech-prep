# Primitive or Not (medium)

Write `isPrimitive(value)`. It returns `true` when the value is a primitive, and `false` when it is an object.

A function is an object too.

Example 1: isPrimitive("a")  ->  true
Example 2: isPrimitive(null)  ->  true
Example 3: isPrimitive([1, 2])  ->  false
Example 4: isPrimitive(() => 1)  ->  false
