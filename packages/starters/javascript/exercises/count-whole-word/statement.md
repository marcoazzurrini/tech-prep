# Count a Whole Word (easy)

Write `countWholeWord(text, word)`. It returns how many times `word` appears in `text` as a whole word, in any mix of capital and small letters.

`word` holds only letters. A match must not have a letter, a digit or `_` right before or after it.

Example 1: countWholeWord("Cat catalog cat.", "cat")  ->  2
Example 2: countWholeWord("bobcat", "cat")  ->  0
Example 3: countWholeWord("a-cat-b", "cat")  ->  1
