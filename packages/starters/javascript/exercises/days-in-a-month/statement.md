# Days in a Month (easy)

Write `daysInMonth(month, leapYear)`. It returns how many days the month has.

`month` is 1 for January, up to 12 for December. It comes as a number, or as text such as `"4"`. `leapYear` is `true` when February has 29 days.

For anything that is not a month, return 0.

Example 1: daysInMonth(1, false)  ->  31
Example 2: daysInMonth("4", false)  ->  30
Example 3: daysInMonth(2, true)  ->  29
Example 4: daysInMonth(13, false)  ->  0
