# Count the Votes (medium)

`countVotes(votes)` takes an array of names, one for each vote. It should return the name with the most votes.

On a tie, the name that got its first vote earlier wins. With no votes, the result is `null`.

The code below throws a `TypeError`. Fix it.

Example 1: countVotes(["tea", "jam", "tea"])  ->  "tea"
Example 2: countVotes(["jam", "tea"])  ->  "jam"
Example 3: countVotes([])  ->  null
