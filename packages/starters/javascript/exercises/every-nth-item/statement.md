# Every Nth Item (easy)

Write `everyNth(list, n)`. It returns a new array with every `n`th item of `list`: the `n`th, the `2n`th, and so on, counting the first item as number 1.

Example 1: everyNth([1, 2, 3, 4, 5, 6], 2)  ->  [2, 4, 6]
Example 2: everyNth([1, 2, 3, 4, 5, 6, 7], 3)  ->  [3, 6]
Example 3: everyNth([1, 2], 3)  ->  []

Constraints: `n` is a whole number, 1 or more.
