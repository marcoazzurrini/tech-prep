# Longest Letter Run (easy)

Write `longestRun(text)`. A run is one character repeated with nothing in between, such as `"bbb"`. Return the longest run in the text.

When two runs are equally long, return the one that comes first. For an empty text, return `""`.

Example 1: longestRun("aabbbc")  ->  "bbb"
Example 2: longestRun("aabb")  ->  "aa"
Example 3: longestRun("abc")  ->  "a"
