# Invert a Colour (medium)

A colour is written as `#` and six hex digits: two for red, two for green and two for blue. Each pair is a value from `00` to `ff`, which is 0 to 255.

Write `invertColour(hex)`. It returns the opposite colour, where each value becomes 255 minus that value. Write the result in small letters, always with six digits.

Example 1: invertColour("#ff8000")  ->  "#007fff"
Example 2: invertColour("#000000")  ->  "#ffffff"
Example 3: invertColour("#FFF0F5")  ->  "#000f0a"
