# Longest Jump (easy)

`longestJump(jumps)` should return the longest jump, as a number. The jumps were read from a file, so each one is a string of digits: a length in centimetres. The array is never empty.

The code below picks the wrong jump for some lists. Fix it.

Example 1: longestJump(["98", "102", "9"])  ->  102
Example 2: longestJump(["45"])  ->  45
