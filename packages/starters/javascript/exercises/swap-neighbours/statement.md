# Swap Neighbours (easy)

Write `swapNeighbours(list)`. It swaps the items of the array in pairs: the first with the second, the third with the fourth, and so on. Then it returns the array.

When the number of items is odd, the last item stays where it is.

Example 1: swapNeighbours([1, 2, 3, 4])  ->  [2, 1, 4, 3]
Example 2: swapNeighbours(["a", "b", "c"])  ->  ["b", "a", "c"]
Example 3: swapNeighbours([])  ->  []
