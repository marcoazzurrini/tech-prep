# Years to Reach a Goal (medium)

Write `yearsToReach(start, goal, ratePercent)`. Savings of `start` grow by `ratePercent` per cent each year, and each year's growth is added to the savings. Return the fewest whole years until the savings are at least `goal`.

If `start` is already at least `goal`, return 0.

Example 1: yearsToReach(100, 150, 10)  ->  5
Example 2: yearsToReach(250, 1000, 100)  ->  2
Example 3: yearsToReach(800, 500, 5)  ->  0

Note: Solve it without a loop. `start` and `ratePercent` are always greater than 0.
