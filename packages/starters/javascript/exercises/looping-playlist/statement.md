# Looping Playlist (medium)

A playlist has `count` tracks, numbered from 0. It loops: after the last track comes track 0 again.

Write `trackAt(position, count)`. `position` is any whole number, and it can be negative: -1 is the last track, -2 the one before it. Return the number of the track at that position.

Example 1: trackAt(7, 5)  ->  2
Example 2: trackAt(-1, 5)  ->  4
Example 3: trackAt(5, 5)  ->  0
