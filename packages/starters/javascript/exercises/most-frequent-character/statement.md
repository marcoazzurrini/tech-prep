# Most Frequent Character (medium)

Write `mostFrequent(text)`. It returns the character that appears most often in the text. Spaces do not count, and capital and small letters are different characters.

An emoji such as `🍕` counts as one character. On a tie, return the character that appears first in the text. When there is no character to count, return `""`.

Example 1: mostFrequent("banana")  ->  "a"
Example 2: mostFrequent("🍕 a 🍕 b")  ->  "🍕"
Example 3: mostFrequent("abba")  ->  "a"
Example 4: mostFrequent("")  ->  ""
