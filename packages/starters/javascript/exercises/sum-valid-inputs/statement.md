# Sum Valid Inputs (easy)

Write `sumValid(inputs)`. It takes an array of strings that users typed, and returns the sum of the ones that are numbers.

Skip a string that is blank, or is not a number.

Example 1: sumValid(["4", " 2.5 ", "abc"])  ->  6.5
Example 2: sumValid(["", "  ", "10"])  ->  10
Example 3: sumValid([])  ->  0
