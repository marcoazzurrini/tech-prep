# Title to Slug (medium)

Write `titleToSlug(title)`. A slug is the title in small letters, with words joined by `-`.

A word is a run of letters and digits, in any script. Everything else, such as spaces, punctuation and emoji, only separates words.

Example 1: titleToSlug("Crème Brûlée: 2 Ways!")  ->  "crème-brûlée-2-ways"
Example 2: titleToSlug("Привет мир")  ->  "привет-мир"
Example 3: titleToSlug("C'est la vie")  ->  "c-est-la-vie"
Example 4: titleToSlug("!!!")  ->  ""
