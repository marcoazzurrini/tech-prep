# Sum of Two Long Numbers (medium)

Write `addLong(a, b)`. It takes two whole numbers, each written as a string of digits, and returns their sum as a string of digits.

The numbers can be far longer than a JavaScript number can hold exactly.

Example 1: addLong("999", "1")  ->  "1000"
Example 2: addLong("12345678901234567890", "1")  ->  "12345678901234567891"
Example 3: addLong("0", "0")  ->  "0"

Note: Solve it without `BigInt`.
