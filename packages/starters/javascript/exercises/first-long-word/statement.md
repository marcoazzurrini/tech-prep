# First Long Word (easy)

`firstLongWords(lines)` takes an array of lines of text. For each line, it should give the first word with more than four letters, or `"-"` when the line has no such word.

The code below gives some lines the word of an earlier line. Fix it.

Example 1: firstLongWords(["a quiet morning", "no rain"])  ->  ["quiet", "-"]
Example 2: firstLongWords(["it is"])  ->  ["-"]
Example 3: firstLongWords([])  ->  []
