# Add Months (medium)

Write `addMonths(day, months)`. It takes a day written as `"YYYY-MM-DD"` and returns the same day `months` months later, in the same form. `months` can be negative.

When the new month is too short for that day, return the last day of the new month.

Example 1: addMonths("2024-03-15", 2)  ->  "2024-05-15"
Example 2: addMonths("2024-01-31", 1)  ->  "2024-02-29"
Example 3: addMonths("2024-05-31", -1)  ->  "2024-04-30"
