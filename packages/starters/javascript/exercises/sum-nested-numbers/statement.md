# Nested Sum (easy)

Write `nestedSum(list)`. `list` is an array. Each item is a number, or another array of the same kind, to any depth. Return the sum of all the numbers.

Example 1: nestedSum([1, [2, 3], [[4]]])  ->  10
Example 2: nestedSum([])  ->  0
Example 3: nestedSum([[], [[]]])  ->  0

Note: Solve it without `flat`.
