# Real Calendar Day (medium)

Write `isRealDay(text)`. It takes a day written as `"YYYY-MM-DD"` and returns `true` when that day exists in the calendar, and `false` when it does not.

February has 29 days in a leap year and 28 in other years. April, June, September and November have 30 days.

Example 1: isRealDay("2024-02-29")  ->  true
Example 2: isRealDay("2023-02-29")  ->  false
Example 3: isRealDay("2024-13-01")  ->  false
Example 4: isRealDay("2024-06-00")  ->  false

Note: the text always has four digits, a dash, two digits, a dash and two digits.
