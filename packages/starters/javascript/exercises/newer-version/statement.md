# Newer Version (medium)

Write `compareVersions(a, b)`. Each version is a string of whole numbers joined by dots, such as `"1.10.2"`.

Return `-1` when `a` is the older version, `1` when `a` is the newer one, and `0` when the two are the same version.

A part that is missing counts as `0`, so `"1.2"` is the same version as `"1.2.0"`.

Example 1: compareVersions("1.9", "1.10")  ->  -1
Example 2: compareVersions("2.0.1", "2.0")  ->  1
Example 3: compareVersions("1.2", "1.2.0")  ->  0
