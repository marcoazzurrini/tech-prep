# First Spelling of Each Word (medium)

Write `distinctWords(text)`. Words in `text` are separated by one or more spaces. Return each different word once, in the order the words first appear.

Words that differ only in capital letters count as the same word. Keep the spelling of its first appearance.

Example 1: distinctWords("The cat saw the Cat")  ->  ["The", "cat", "saw"]
Example 2: distinctWords("  Hi   hi HI there ")  ->  ["Hi", "there"]
Example 3: distinctWords("")  ->  []
