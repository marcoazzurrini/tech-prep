# Seat Row (medium)

A cinema row has five seats, numbered 0 to 4. `seatRow(taken)` takes the numbers of the taken seats. It should return the row as text, with `X` for a taken seat and `-` for a free one.

The code below is right on the first call and wrong after it. Fix it.

Example 1: seatRow([0, 3])  ->  "X--X-"
Example 2: seatRow([])  ->  "-----"
Example 3:
  seatRow([0, 1]);
  seatRow([4])  ->  "----X"
