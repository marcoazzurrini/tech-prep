# Price in Cents (medium)

Write `toCents(text)`. It takes a price that a user typed, such as `"19.99"`, and returns the price in whole cents.

Return `null` when the text is not a valid price: it is blank, it is not numeric, it is negative or it is infinite.

Example 1: toCents("19.99")  ->  1999
Example 2: toCents(" 3 ")  ->  300
Example 3: toCents("three")  ->  null
Example 4: toCents("")  ->  null
