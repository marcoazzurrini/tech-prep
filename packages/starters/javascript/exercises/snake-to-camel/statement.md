# Snake Case to Camel Case (easy)

Write `snakeToCamel(name)`. It takes a name in snake case, such as `"user_first_name"`, and returns it in camel case, such as `"userFirstName"`.

In snake case, the words are lowercase and joined by one underscore. In camel case, the words are joined with nothing between them, and every word but the first starts with a capital letter.

Example 1: snakeToCamel("user_first_name")  ->  "userFirstName"
Example 2: snakeToCamel("order_id_2")  ->  "orderId2"
Example 3: snakeToCamel("id")  ->  "id"
