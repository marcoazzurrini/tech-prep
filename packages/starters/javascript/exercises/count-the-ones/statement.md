# Count the Ones (medium)

Write `countOnes(n)`. It returns how many of the 32 bits of `n` are 1.

`n` is a whole number that fits in 32 bits, and it may be negative. The number 5 is `101` in bits, so it has two. The number -1 has all 32 bits set.

Example 1: countOnes(5)  ->  2
Example 2: countOnes(8)  ->  1
Example 3: countOnes(0)  ->  0
Example 4: countOnes(-1)  ->  32

Note: Solve it without `toString`.
