# Move an Item (easy)

Write `moveItem(list, from, to)`. It takes the item at index `from` out of `list` and puts it back so that it ends up at index `to`. The other items keep their order.

Change `list` itself, and return it.

Example 1: moveItem(["a", "b", "c", "d"], 0, 2)  ->  ["b", "c", "a", "d"]
Example 2: moveItem([1, 2, 3], 2, 0)  ->  [3, 1, 2]
Example 3: moveItem([1, 2, 3], 1, 1)  ->  [1, 2, 3]

Constraints: `from` and `to` are valid indexes of `list`.
