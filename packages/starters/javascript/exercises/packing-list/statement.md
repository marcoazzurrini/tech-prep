# Packing List (easy)

`packingList(items, prefix)` takes the names of the items in a parcel. It should return one line for each item: the `prefix`, then the name.

The code below throws a `ReferenceError`. Fix it.

Example 1: packingList(["tea", "milk"], "- ")  ->  ["- tea", "- milk"]
Example 2: packingList([], "* ")  ->  []
