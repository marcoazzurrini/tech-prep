# Free in Every Calendar (medium)

Write `sharedFreeHours(calendars)`. Each calendar is an array of the hours in which one person is free. An hour can appear more than once in a calendar.

Return the hours in which every person is free, each hour once, from earliest to latest. With no calendars at all, return an empty array.

Example 1: sharedFreeHours([[9, 10, 11, 14], [10, 11, 15], [11, 10, 9]])  ->  [10, 11]
Example 2: sharedFreeHours([[9, 10], [11, 12]])  ->  []
Example 3: sharedFreeHours([[8, 9]])  ->  [8, 9]
