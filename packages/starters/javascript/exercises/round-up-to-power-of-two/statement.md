# Round Up to a Power of Two (medium)

Write `roundUpToPowerOfTwo(n)`. It returns the smallest power of two that is at least `n`. The powers of two are 1, 2, 4, 8, 16 and so on.

A hash table uses this to pick its size, so it must be exact for every `n` in range.

Example 1: roundUpToPowerOfTwo(1000)  ->  1024
Example 2: roundUpToPowerOfTwo(1024)  ->  1024
Example 3: roundUpToPowerOfTwo(1)  ->  1
Example 4: roundUpToPowerOfTwo(2147483648)  ->  2147483648

Constraints: `n` is a whole number from 1 to 2147483648.
