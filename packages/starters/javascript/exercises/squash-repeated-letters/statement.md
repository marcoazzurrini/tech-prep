# Squash Repeats (medium)

Write `squash(text)`. It returns a shorter form of the text, where each run of the same character becomes the character and the length of the run.

A character that stands alone keeps no number. Upper and lower case are different characters.

Example 1: squash("aaabcc")  ->  "a3bc2"
Example 2: squash("aabaa")  ->  "a2ba2"
Example 3: squash("abc")  ->  "abc"
Example 4: squash("")  ->  ""

Constraints: the text holds no digits.
