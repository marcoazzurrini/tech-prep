# Format Thousands (medium)

Write `formatThousands(n)`. It takes a number and returns it as a string, with a comma between each group of three digits in the whole part. Count the groups from the right.

Keep the minus sign and the decimal part as they are.

Example 1: formatThousands(1234567.5)  ->  "1,234,567.5"
Example 2: formatThousands(-9876543)  ->  "-9,876,543"
Example 3: formatThousands(999)  ->  "999"
Example 4: formatThousands(0.25)  ->  "0.25"

Note: solve it without `toLocaleString` or `Intl`.
