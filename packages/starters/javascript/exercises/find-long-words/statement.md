# Find Long Words (easy)

Write `findLongWords(text, min)`. It returns every word in `text` with at least `min` letters, in order.

A word is a run of the letters `a` to `z`, in either case. Any other character ends a word. `min` is a whole number of 1 or more.

Example 1: findLongWords("The quick brown fox", 5)  ->  ["quick", "brown"]
Example 2: findLongWords("abc123defg", 4)  ->  ["defg"]
Example 3: findLongWords("Hi", 3)  ->  []
