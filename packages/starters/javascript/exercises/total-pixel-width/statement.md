# Total Width (easy)

Write `totalWidth(widths)`. It takes an array of CSS widths such as `"120px"` and returns their sum in pixels.

A width that does not start with a number, such as `"auto"`, counts as 0.

Example 1: totalWidth(["120px", "8.5px", "auto"])  ->  128.5
Example 2: totalWidth(["-4px", "10px"])  ->  6
Example 3: totalWidth([])  ->  0
