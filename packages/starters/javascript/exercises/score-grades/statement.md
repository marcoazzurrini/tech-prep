# Score Grades (easy)

Finish this file so that other files can use two names from it, and nothing else:

- `MAX_SCORE`, the number 100.
- `grade(score)`, which returns `"A"` from 90 up, `"B"` from 75 up, `"C"` from 50 up, and `"F"` below 50. A score above `MAX_SCORE` or below 0 gives `"invalid"`.

Example 1: grade(92)  ->  "A"
Example 2: grade(50)  ->  "C"
Example 3: grade(101)  ->  "invalid"
Example 4: Object.keys(exports)  ->  ["MAX_SCORE", "grade"]
