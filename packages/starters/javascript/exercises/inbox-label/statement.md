# Inbox Label (easy)

Write `inboxLabel(name, count)`. It returns the line an inbox shows to a user, from the user's name and the number of new messages.

Example 1: inboxLabel("Ada", 3)  ->  "Ada, you have 3 new messages"
Example 2: inboxLabel("Ada", 1)  ->  "Ada, you have 1 new message"
Example 3: inboxLabel("Bo", 0)  ->  "Bo, you have no new messages"
