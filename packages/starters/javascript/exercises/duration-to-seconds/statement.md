# Duration in Seconds (medium)

Write `toSeconds(duration)`. A duration is text such as `"1h 30m 15s"`. It has parts with one space between them, and each part is a whole number followed by `h`, `m` or `s`.

Return the duration in seconds. An empty string is 0 seconds.

Example 1: toSeconds("1h 30m 15s")  ->  5415
Example 2: toSeconds("45s")  ->  45
Example 3: toSeconds("2h 5s")  ->  7205
Example 4: toSeconds("")  ->  0
