# Exact Factorial (medium)

The factorial of `n` is the product of every whole number from 1 to `n`. It grows fast: the factorial of 25 has 26 digits.

Write `factorial(n)`. It takes a whole number from 0 up, as a number. It returns the exact factorial, as a BigInt. The factorial of 0 is 1.

Example 1: factorial(5)  ->  120n
Example 2: factorial(0)  ->  1n
Example 3: factorial(25)  ->  15511210043330985984000000n
