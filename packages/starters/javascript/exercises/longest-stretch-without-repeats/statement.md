# Longest Stretch Without Repeats (medium)

Write `longestDistinctRun(text)`. It returns the length of the longest stretch of neighbouring characters in `text` in which no character appears twice.

Example 1: longestDistinctRun("abcabcbb")  ->  3
Example 2: longestDistinctRun("pwwkew")  ->  3
Example 3: longestDistinctRun("bbbb")  ->  1
Example 4: longestDistinctRun("")  ->  0

Constraints: `text` can be 100000 characters long, so look at each character only a few times.
