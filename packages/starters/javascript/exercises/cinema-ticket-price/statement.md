# Cinema Ticket Price (easy)

`ticketPrice(age, day)` should return the price of a cinema ticket. A ticket costs 12 on `"sat"` and `"sun"`, and 10 on every other day.

A child under 12 pays half. A visitor aged 65 or more pays 3 less.

The code below throws. Fix it.

Example 1: ticketPrice(30, "mon")  ->  10
Example 2: ticketPrice(8, "sat")  ->  6
Example 3: ticketPrice(70, "sun")  ->  9
