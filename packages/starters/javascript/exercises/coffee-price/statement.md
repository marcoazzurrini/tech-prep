# Coffee Price (easy)

`coffeePrice(size, extraShot)` should return the price of a coffee. A `"small"` costs 2 and a `"large"` costs 3. An extra shot adds 1.

The code below throws. Fix it. The price list must stay as it is: the next customer pays the same prices.

Example 1: coffeePrice("small", false)  ->  2
Example 2: coffeePrice("small", true)  ->  3
Example 3: coffeePrice("large", true)  ->  4
