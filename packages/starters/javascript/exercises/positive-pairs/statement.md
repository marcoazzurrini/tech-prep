# Positive Pairs (easy)

Write `positivePairs(nums)`. For each number `n` in `nums`, if `n > 0` include `n` followed by `n * 2`. Drop zero and negative numbers.

Return a single flat array of numbers.

Example 1: positivePairs([3, -1, 0, 5])  ->  [3, 6, 5, 10]
Example 2: positivePairs([-2, 0])  ->  []
Example 3: positivePairs([])  ->  []
