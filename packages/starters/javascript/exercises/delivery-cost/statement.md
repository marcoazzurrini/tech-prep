# Delivery Cost (medium)

`deliveryCost(km, express)` should return the cost of a delivery. A delivery costs 2 for each kilometre, or 3 for each kilometre when it is express.

The code below is right for an express delivery and wrong for every other one. Fix it.

Example 1: deliveryCost(10, false)  ->  20
Example 2: deliveryCost(10, true)  ->  30
