# Power of Two (medium)

Write `isPowerOfTwo(n)`. It returns `true` when `n` is 1, 2, 4, 8 or any number you reach by doubling again. It returns `false` for every other number.

`n` is a whole number from -2147483648 to 2147483647. Zero and negative numbers give `false`.

Example 1: isPowerOfTwo(8)  ->  true
Example 2: isPowerOfTwo(6)  ->  false
Example 3: isPowerOfTwo(1)  ->  true
Example 4: isPowerOfTwo(0)  ->  false
