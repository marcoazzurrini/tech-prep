# First Missing Code (easy)

Write `firstMissingCode(allowed, codes)`. Return the first value in `codes` that does not appear in `allowed`, or `null` when every value is allowed.

Treat `NaN` as matching `NaN`.

Example 1: firstMissingCode([1, 2, 3], [2, 4, 1])  ->  4
Example 2: firstMissingCode([1, 2], [2, 1])  ->  null
Example 3: firstMissingCode([NaN, 1], [NaN, 2])  ->  2
