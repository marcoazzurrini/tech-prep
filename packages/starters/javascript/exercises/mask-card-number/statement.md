# Mask a Card Number (easy)

Write `maskCard(number)`. It takes a card number as a string. It returns a string of the same length, where every character but the last four is `*`.

A string of four characters or fewer comes back as it is.

Example 1: maskCard("4111222233334444")  ->  "************4444"
Example 2: maskCard("12345")  ->  "*2345"
Example 3: maskCard("123")  ->  "123"
