# Stock Line (medium)

A shop holds `count` items, and `reserved` of them are already promised. `stockLine(count, reserved)` should return a line of text that says how many are left to sell, and whether any are left.

The code below returns the wrong text. Fix it.

Example 1: stockLine(10, 4)  ->  "Left: 6 (in stock)"
Example 2: stockLine(3, 3)  ->  "Left: 0 (sold out)"
