# Rotate a List (medium)

Write `rotateRight(list, k)`. It returns a new array where every item has moved `k` places to the right. An item pushed past the end comes back in at the start.

Do not change `list`.

Example 1: rotateRight([1, 2, 3, 4, 5], 2)  ->  [4, 5, 1, 2, 3]
Example 2: rotateRight([1, 2, 3], 4)  ->  [3, 1, 2]
Example 3: rotateRight([], 3)  ->  []

Constraints: `k` is a whole number, 0 or more. It can be larger than the length.
