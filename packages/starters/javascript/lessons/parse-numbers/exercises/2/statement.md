Write `hexToRgb(colour)`. It takes a colour such as `"#ff8800"`: a `#`, then two base 16 digits each for red, green and blue.

Return the three parts as numbers, in an array.

Example 1: hexToRgb("#ff8800")  ->  [255, 136, 0]
Example 2: hexToRgb("#000000")  ->  [0, 0, 0]
Example 3: hexToRgb("#0a0b0c")  ->  [10, 11, 12]
