Write `readHashtags(text)`. A hashtag is a `#` followed by word characters: letters, digits and `_`.

Return the word of each hashtag, without the `#`, in order.

Example 1: readHashtags("Loving #summer and #sea")  ->  ["summer", "sea"]
Example 2: readHashtags("#a#b")  ->  ["a", "b"]
Example 3: readHashtags("no tags here")  ->  []
