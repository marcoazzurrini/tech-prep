Write `checkPassword(password)`. It returns `true` when the password follows every rule, and `false` otherwise:

- it has at least 10 characters,
- it has a small letter,
- it has a digit,
- it has one of the symbols `!@#$%`.

Example 1: checkPassword("correcthorse1!")  ->  true
Example 2: checkPassword("Short1!")  ->  false
Example 3: checkPassword("nosymbol1234")  ->  false
