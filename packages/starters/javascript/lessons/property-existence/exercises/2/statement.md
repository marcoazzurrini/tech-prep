Write `knownWords(dictionary, words)`. The dictionary maps a word to its meaning.

Return the words of the list that the dictionary holds itself, in the same order. A word with an empty meaning still counts.

Example 1: knownWords({ cat: "an animal" }, ["cat", "dog"])  ->  ["cat"]
Example 2: knownWords({ cat: "an animal" }, ["toString", "cat"])  ->  ["cat"]
