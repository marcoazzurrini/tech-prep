Write `lastPassingStudent(entries)`. Each entry has a `student` name and a `score`. Return the `student` of the last entry with a score of at least `60`, or `"none"` if no one passed.

Do not change the input array.

Example 1: lastPassingStudent([{ student: "Lin", score: 70 }, { student: "Bo", score: 85 }])  ->  "Bo"
Example 2: lastPassingStudent([{ student: "Lin", score: 60 }, { student: "Bo", score: 40 }])  ->  "Lin"
Example 3: lastPassingStudent([{ student: "Lin", score: 30 }])  ->  "none"
