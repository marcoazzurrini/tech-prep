Write `toHexCode(n)`. It returns `n` in base 16, as `0x` followed by exactly four digits. Use capital letters for the digits from A to F.

Example 1: toHexCode(255)  ->  "0x00FF"
Example 2: toHexCode(48879)  ->  "0xBEEF"
Example 3: toHexCode(0)  ->  "0x0000"

Note: `n` is a whole number from 0 to 65535.
