`firstWords(source, n)` returns the first `n` words of `source`, in capitals. `source` can be an array, a `Set`, a built-in iterator, or a hand-made iterator that has only a `next()` method.

The code below works only for built-in iterators. Fix it.

Example 1: firstWords(["tea", "jam"], 1)  ->  ["TEA"]
Example 2: firstWords(new Set(["a", "b", "c"]), 2)  ->  ["A", "B"]
