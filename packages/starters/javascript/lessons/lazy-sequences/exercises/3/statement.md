Write `firstSquaresOver(limit, count)`. It returns an array of the first `count` square numbers that are greater than `limit`. The square numbers are 1, 4, 9, 16 and so on.

Start from an endless generator of whole numbers, and use the iterator helpers.

Example 1: firstSquaresOver(10, 3)  ->  [16, 25, 36]
Example 2: firstSquaresOver(0, 2)  ->  [1, 4]
