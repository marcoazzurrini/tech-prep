Write `weekdayName(year, month, day)`. It returns the English name of the day of the week, such as `"Monday"`.

The month is written as people write it: `1` is January and `12` is December.

Example 1: weekdayName(2024, 1, 15)  ->  "Monday"
Example 2: weekdayName(2024, 12, 25)  ->  "Wednesday"
Example 3: weekdayName(2000, 1, 1)  ->  "Saturday"
