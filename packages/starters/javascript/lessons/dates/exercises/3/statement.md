`addDays(date, days)` should return a new date, `days` days after the one it is given. The date it is given must not change.

The code below changes the date it is given. Fix it.

Example 1: addDays(new Date("2024-01-30"), 3)  ->  a date on 2024-02-02
Example 2: addDays(new Date("2024-03-01"), -1)  ->  a date on 2024-02-29
