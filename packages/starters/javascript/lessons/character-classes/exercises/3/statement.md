Write `isPlate(text)`. A plate is two capital letters followed by two digits, and nothing else. Return `true` when `text` is a plate, and `false` otherwise.

Example 1: isPlate("AB12")  ->  true
Example 2: isPlate("ab12")  ->  false
Example 3: isPlate("AB123")  ->  false
Example 4: isPlate("XAB12")  ->  false
