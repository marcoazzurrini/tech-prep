Write `stripPunctuation(text)`. It returns `text` with only its letters `A` to `Z` in either case, its digits and its spaces. Every other character is removed.

Example 1: stripPunctuation("Hello, world!")  ->  "Hello world"
Example 2: stripPunctuation("It's 5 o'clock.")  ->  "Its 5 oclock"
Example 3: stripPunctuation("a-b_c")  ->  "abc"
