Write `findPrice(menu, dish)`. The menu is an array of items, each with a `dish` and a `price`. Return the price of the dish.

When the dish is not on the menu, return `null`. Do not return `undefined`.

Example 1: findPrice([{ dish: "soup", price: 4 }], "soup")  ->  4
Example 2: findPrice([{ dish: "soup", price: 4 }], "cake")  ->  null
