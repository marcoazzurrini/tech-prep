Write `angleOf(x, y)`. It returns the angle of the point (x, y), in degrees. The angle starts at the positive x axis and turns towards the positive y axis.

The result runs from 0 up to, but not including, 360. Round it to the nearest whole degree.

Example 1: angleOf(1, 1)  ->  45
Example 2: angleOf(-1, 0)  ->  180
Example 3: angleOf(0, -1)  ->  270
Example 4: angleOf(3, 4)  ->  53
