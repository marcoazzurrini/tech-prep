Write `hasDoubledWord(text)`. It returns `true` when some word appears twice in a row, with only whitespace between, in any mix of capital and small letters. Otherwise it returns `false`.

A word is a run of word characters: letters, digits and `_`.

Example 1: hasDoubledWord("This is is fine")  ->  true
Example 2: hasDoubledWord("The the end")  ->  true
Example 3: hasDoubledWord("is island")  ->  false
