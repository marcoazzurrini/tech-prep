Write `formatPhone(digits)`. When `digits` is exactly ten digits, return it as `(AAA) BBB-CCCC`: the first three digits in brackets, a space, the next three, a dash and the last four.

Return any other text unchanged.

Example 1: formatPhone("4155550123")  ->  "(415) 555-0123"
Example 2: formatPhone("12345")  ->  "12345"
Example 3: formatPhone("41555501234")  ->  "41555501234"
