Write `makeRange(min, max)`. It returns an object for the `in` operator: `n in range` is `true` when `n` is a number from `min` to `max`, both included.

Any other key gives `false`.

Example 1: 3 in makeRange(1, 5)  ->  true
Example 2: 9 in makeRange(1, 5)  ->  false
Example 3: "x" in makeRange(1, 5)  ->  false
