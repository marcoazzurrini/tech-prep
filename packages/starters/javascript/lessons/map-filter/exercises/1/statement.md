Write `withRank(players)`. It takes an array of player objects, best first. It returns a new array of new objects: each player with a `rank` property added, from `1` for the first player.

Example 1: withRank([{ name: "Ada" }, { name: "Bo" }])  ->  [{ name: "Ada", rank: 1 }, { name: "Bo", rank: 2 }]
Example 2: withRank([])  ->  []
