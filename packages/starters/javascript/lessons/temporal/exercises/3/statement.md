Write `ageOn(birthday, day)`. Both are dates written as `"YYYY-MM-DD"`. It returns how many full years old a person born on `birthday` is on `day`.

Example 1: ageOn("1990-06-15", "2024-06-14")  ->  33
Example 2: ageOn("1990-06-15", "2024-06-15")  ->  34
Example 3: ageOn("2024-01-01", "2024-12-31")  ->  0
