A dish of cells doubles every day. Write `cellsAfter(cells, days)`. It returns how many cells there are after `days` days, starting from `cells`.

Use recursion: no loop and no `**`. After 0 days the count has not changed. That is the base case.

Example 1: cellsAfter(3, 0)  ->  3
Example 2: cellsAfter(3, 1)  ->  6
Example 3: cellsAfter(5, 3)  ->  40
