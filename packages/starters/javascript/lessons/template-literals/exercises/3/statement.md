Write `addressLabel(person)`. A person has a `name`, a `street`, a `zip` and a `city`. Return a label of three lines: the name, the street, then the zip and the city with one space between them.

No line starts with a space, and the label does not end with a line break.

Example 1:
  addressLabel({ name: "Ada Low", street: "12 Hill Road", zip: "1050", city: "Oslo" })
  ->  "Ada Low\n12 Hill Road\n1050 Oslo"
