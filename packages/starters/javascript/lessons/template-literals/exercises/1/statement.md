Write `orderLine(item)`. An item has a `name`, a `price` and a `count`. Return one line of text: the count, the name and the price of them all together.

Example 1: orderLine({ name: "mug", price: 6, count: 3 })  ->  "3 x mug = 18"
Example 2: orderLine({ name: "cap", price: 12, count: 1 })  ->  "1 x cap = 12"
