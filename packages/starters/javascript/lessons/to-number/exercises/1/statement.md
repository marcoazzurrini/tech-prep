Write `readAmount(text)`. It takes the text that a user typed and returns it as a number.

Return `null` when the text is blank, or is not a number.

Example 1: readAmount("12.5")  ->  12.5
Example 2: readAmount("  ")  ->  null
Example 3: readAmount("12 kg")  ->  null
Example 4: readAmount("0")  ->  0
