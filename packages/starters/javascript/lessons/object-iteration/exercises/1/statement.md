Write `priciest(menu)`. The menu maps a dish to its price.

Return the name of the dish with the highest price. When two dishes share it, return the one that comes first in the menu. Return `null` for an empty menu.

Example 1: priciest({ soup: 4, steak: 18, cake: 6 })  ->  "steak"
Example 2: priciest({})  ->  null

Note: A price is zero or more.
