Write `packColour(red, green, blue)`. Each argument is a whole number from 0 to 255. It packs the three into one number.

Return `red` moved 16 bits to the left, plus `green` moved 8 bits to the left, plus `blue`.

Example 1: packColour(0, 0, 255)  ->  255
Example 2: packColour(0, 1, 0)  ->  256
Example 3: packColour(255, 136, 0)  ->  16746496
