Write `shortDay(text)`. It takes a date written as `"YYYY-MM-DD"` and returns a short label in British English (`en-GB`): the short weekday, the day and the short month.

The label must be the same on a computer in any time zone.

Example 1: shortDay("2024-01-15")  ->  "Mon 15 Jan"
Example 2: shortDay("2000-02-29")  ->  "Tue 29 Feb"
