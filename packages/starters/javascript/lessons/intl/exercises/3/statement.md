Write `polishFiles(n)`. It returns the number and the Polish word for "file" in the right form, using the plural rules of Polish (`pl`).

The four forms are:
- `one`: plik
- `few`: pliki
- `many`: plików
- `other`: pliku

Example 1: polishFiles(1)  ->  "1 plik"
Example 2: polishFiles(2)  ->  "2 pliki"
Example 3: polishFiles(5)  ->  "5 plików"
