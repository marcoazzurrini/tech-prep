Write `countWords(words)`. It takes an array of words and returns an array of `[word, count]` pairs.

The pairs come in the order in which each word first appears. Any string can be a word.

Example 1: countWords(["tea", "cake", "tea"])  ->  [["tea", 2], ["cake", 1]]
Example 2: countWords(["10", "2", "10"])  ->  [["10", 2], ["2", 1]]
Example 3: countWords([])  ->  []
