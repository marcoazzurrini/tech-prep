Write `cheapItems(prices, limit)`. `prices` is a `Map` from an item to its price.

Return an array of the items that cost `limit` or less, in the order of the map.

Example 1: cheapItems(new Map([["tea", 3], ["cake", 5], ["jam", 2]]), 3)  ->  ["tea", "jam"]
Example 2: cheapItems(new Map(), 10)  ->  []
