Write `maskCard(number)`. It takes a card number as a string of digits. It returns a string of the same length, with every digit but the last four replaced by `*`.

A number of four digits or fewer comes back as it is.

Example 1: maskCard("4111222233334444")  ->  "************4444"
Example 2: maskCard("12345")  ->  "*2345"
Example 3: maskCard("987")  ->  "987"
