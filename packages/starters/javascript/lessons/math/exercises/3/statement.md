Write `biggestSwing(readings)`. It takes a list of temperatures and returns the largest change between two readings that sit next to each other. A change counts the same up or down.

With fewer than two readings there is no change, so return `0`.

Example 1: biggestSwing([4, -7, 12, 10])  ->  19
Example 2: biggestSwing([5, 1])  ->  4
Example 3: biggestSwing([3])  ->  0
