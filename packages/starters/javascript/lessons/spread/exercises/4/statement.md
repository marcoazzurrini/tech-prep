Write `sendToBack(queue)`. It returns a new array in which the first item of `queue` has moved to the end.

An empty queue gives an empty array. The function must not change `queue`.

Example 1: sendToBack(["Ada", "Ben", "Cy"])  ->  ["Ben", "Cy", "Ada"]
Example 2: sendToBack(["Ada"])  ->  ["Ada"]
Example 3: sendToBack([])  ->  []
