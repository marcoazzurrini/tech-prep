Write `foreignLetters(text)`. It returns every letter of the text that is not an ASCII letter, joined in order. The ASCII letters are `a` to `z` and `A` to `Z`.

Example 1: foreignLetters("Ä b γ")  ->  "Äγ"
Example 2: foreignLetters("Crème brûlée")  ->  "èûé"
Example 3: foreignLetters("plain")  ->  ""
