Write `numberAt(text, position)`. It returns the whole number whose digits start exactly at `position`, as a number. When the character at `position` is not a digit, it returns `null`.

Example 1: numberAt("abc 123 x", 4)  ->  123
Example 2: numberAt("abc 123 x", 5)  ->  23
Example 3: numberAt("abc 123 x", 3)  ->  null
