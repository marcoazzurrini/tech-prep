Write `teamLine(captain, ...players)`. It takes the name of the captain, then any number of player names.

It returns `"<captain> leads <players>"`, with the players joined by `", "`. With no players, it returns `"<captain> plays alone"`.

Example 1: teamLine("Ada", "Ben", "Cy")  ->  "Ada leads Ben, Cy"
Example 2: teamLine("Lin", "Max")  ->  "Lin leads Max"
Example 3: teamLine("Ada")  ->  "Ada plays alone"
