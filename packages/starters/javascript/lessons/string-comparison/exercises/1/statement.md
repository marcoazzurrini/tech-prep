Write `firstAlphabetically(words)`. It returns the word that comes first in alphabetical order, ignoring case. Return it spelled as it is in the array.

For an empty array, return `""`.

Example 1: firstAlphabetically(["pear", "Apple", "banana"])  ->  "Apple"
Example 2: firstAlphabetically(["b", "A"])  ->  "A"
Example 3: firstAlphabetically([])  ->  ""
