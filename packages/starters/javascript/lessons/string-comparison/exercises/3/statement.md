Write `findContact(names, query)`. It returns the first name in the array that is equal to `query` when case and accents are ignored. Return it spelled as it is in the array.

When no name matches, return `""`.

Example 1: findContact(["Zoë", "Ana", "Émile"], "zoe")  ->  "Zoë"
Example 2: findContact(["Jose", "José"], "JOSÉ")  ->  "Jose"
Example 3: findContact(["Ana"], "Anna")  ->  ""
