`dotsToUnderscores(version)` should replace every dot in `version` with an underscore, and keep every other character.

The code below turns every character into an underscore. Fix it.

Example 1: dotsToUnderscores("1.2.3")  ->  "1_2_3"
Example 2: dotsToUnderscores("v10.0")  ->  "v10_0"
Example 3: dotsToUnderscores("2024")  ->  "2024"
