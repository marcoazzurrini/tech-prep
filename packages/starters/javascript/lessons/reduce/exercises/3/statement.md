Write `stats(numbers)`. It returns an object with four properties: `count`, `sum`, `min` and `max` of the numbers.

For an empty array, `count` and `sum` are `0`, and `min` and `max` are `null`.

Example 1: stats([4, 9, 2])  ->  { count: 3, sum: 15, min: 2, max: 9 }
Example 2: stats([])  ->  { count: 0, sum: 0, min: null, max: null }
