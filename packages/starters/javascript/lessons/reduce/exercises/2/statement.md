Write `longestWord(words)`. It returns the longest string in `words`. When two are equally long, return the first of them. For an empty array, return `""`.

Example 1: longestWord(["tea", "coffee", "milk"])  ->  "coffee"
Example 2: longestWord(["ab", "cd", "e"])  ->  "ab"
Example 3: longestWord([])  ->  ""
