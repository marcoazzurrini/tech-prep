`menu(title, dishes)` should return one line of text: the title with a colon, then each dish with `- ` before it.

The code below loses the title when there is at least one dish. Fix it.

Example 1: menu("Lunch", ["soup", "rice"])  ->  "Lunch: - soup - rice"
Example 2: menu("Closed", [])  ->  "Closed:"
