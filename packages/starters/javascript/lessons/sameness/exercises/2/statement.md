Write `countDifferent(values)`. It takes an array and returns how many different values it holds.

`NaN` counts once, however often it appears. `0` and `-0` count as one value.

Example 1: countDifferent([3, 3, 5])  ->  2
Example 2: countDifferent([NaN, NaN, 1])  ->  2
Example 3: countDifferent([0, -0, 0])  ->  1
