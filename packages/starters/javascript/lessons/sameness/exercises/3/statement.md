Write `countMatches(list, target)`. It returns how many items of `list` are the same as `target`.

Compare as `includes` does: `NaN` matches `NaN`, and `0` matches `-0`. Nothing is converted.

Example 1: countMatches([1, 2, 1], 1)  ->  2
Example 2: countMatches([NaN, 4, NaN], NaN)  ->  2
Example 3: countMatches(["1", 1], 1)  ->  1
