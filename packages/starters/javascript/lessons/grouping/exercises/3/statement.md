Write `sumByCategory(items)`.

Each item has a `category` string and an `amount` number. Return an object mapping each `category` to the sum of its `amount` values.

Example 1: sumByCategory([{ category: "food", amount: 12 }, { category: "books", amount: 8 }, { category: "food", amount: 5 }])  ->  { food: 17, books: 8 }
Example 2: sumByCategory([])  ->  {}
