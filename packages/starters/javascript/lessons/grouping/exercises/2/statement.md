Write `countWords(words)`.

Return an object mapping each word in `words` to how many times it appears. Handle any string, including names like `"constructor"` and `"toString"`.

Example 1: countWords(["a", "b", "a"])  ->  { a: 2, b: 1 }
Example 2: countWords(["toString", "toString"])  ->  { toString: 2 }
Example 3: countWords([])  ->  {}
