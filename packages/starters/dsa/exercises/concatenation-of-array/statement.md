# Concatenation of Array (easy)

Given an integer array `nums` of length `n`, return a new array of length `2n`. It holds the items of `nums` in order, followed by the items of `nums` in order again.

Example 1: nums = [1, 2, 1]  ->  [1, 2, 1, 1, 2, 1]
Example 2: nums = [1, 3, 2, 1]  ->  [1, 3, 2, 1, 1, 3, 2, 1]

Constraints: 1 <= len(nums) <= 1000, 1 <= nums[i] <= 1000.
