# Convert Binary Number in a Linked List to Integer (easy)

You get the `head` of a linked list. Each node holds one bit: `0` or `1`. Read from the head to the end, the bits form a binary number. The head holds the highest bit. Return the number as a normal integer.

Example 1: head = [1, 0, 1]  ->  5
Example 2: head = [0]  ->  0
Example 3: head = [1, 1, 1, 1]  ->  15

Constraints: 1 <= number of nodes <= 30, each Node.val is 0 or 1.
