# Permutation in String (medium)

Given two strings `s1` and `s2`, return `true` if `s2` contains a substring that is a rearrangement of `s1`. The substring must use every letter of `s1`, the same number of times, and nothing else.

Example 1: s1 = "ab", s2 = "eidbaooo"  ->  true   ("ba" is in s2)
Example 2: s1 = "ab", s2 = "eidboaoo"  ->  false

Constraints: 1 <= len(s1), len(s2) <= 10^4, lowercase English letters.
