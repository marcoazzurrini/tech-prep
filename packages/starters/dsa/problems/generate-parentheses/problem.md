# Generate Parentheses (medium)

Given a number `n`, return every valid string made of `n` pairs of round brackets. A string is valid when every `(` is closed by a later `)`, and no `)` comes before its `(`. Return the strings in any order.

Example 1: n = 1  ->  ["()"]
Example 2: n = 3  ->  ["((()))", "(()())", "(())()", "()(())", "()()()"]

Constraints: 1 <= n <= 8.
