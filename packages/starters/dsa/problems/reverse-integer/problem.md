# Reverse Integer (medium)

Given a signed 32-bit integer `x`, return `x` with its digits in reverse order. Keep the sign.

If the reversed number does not fit in a signed 32-bit integer, return `0`. The allowed range is -2^31 to 2^31 - 1.

Example 1: x = 123  ->  321
Example 2: x = -123  ->  -321
Example 3: x = 120  ->  21
Example 4: x = 1534236469  ->  0
  The reversed number 9646324351 is too large.

Constraints: -2^31 <= x <= 2^31 - 1.
