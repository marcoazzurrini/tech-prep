# Single Number (easy)

In the array `nums`, every value appears exactly twice, except one value that appears once. Return the value that appears once.

Example 1: nums = [2, 2, 1]  ->  1
Example 2: nums = [4, 1, 2, 1, 2]  ->  4
Example 3: nums = [1]  ->  1

Constraints: 1 <= len(nums) <= 3 * 10^4, -3 * 10^4 <= nums[i] <= 3 * 10^4.
Follow-up: can you do it in O(n) time with O(1) extra space?
