# Diameter of Binary Tree (easy)

Given the `root` of a binary tree, return its diameter: the number of edges on the longest path between any two nodes. The path does not have to pass through the root.

Example 1: root = [1, 2, 3, 4, 5]  ->  3  (4 -> 2 -> 1 -> 3)
Example 2: root = [1, 2]  ->  1
Example 3: root = [1]  ->  0

Trees are shown in level order, with `null` for a missing child.
Constraints: 1 <= number of nodes <= 10^4, -100 <= Node.val <= 100.
