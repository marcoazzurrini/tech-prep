# Sum of the First Half (easy)

You get the `head` of a linked list. Return the sum of the values in its first half. Walk the list only once, and do not count the nodes first.

When the number of nodes is odd, the middle node is not part of the first half.

Example 1: head = [1, 2, 3, 4] -> 3 (1 + 2) Example 2: head = [5, 1, 9, 7, 2] -> 6 (5 + 1; the middle node 9 is left out) Example 3: head = [8] -> 0

Constraints: 0 <= number of nodes <= 100, 0 <= Node.val <= 1000.
