# Insert into a Sorted List (easy)

You get the `head` of a linked list sorted in non-decreasing order, and a number `val`. Add a new node with the value `val`, so that the list stays sorted. Return the head of the list.

The new node may become the new head.

Example 1: head = [1, 3, 5], val = 4 -> [1, 3, 4, 5] Example 2: head = [2, 6], val = 1 -> [1, 2, 6] Example 3: head = [], val = 7 -> [7]

Constraints: 0 <= number of nodes <= 100, -1000 <= Node.val, val <= 1000, the list is sorted.
