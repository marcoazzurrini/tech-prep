# Count the Leaves (easy)

Given the `root` of a binary tree, return the number of leaves. A leaf is a node with no children. An empty tree has no leaves.

Example 1: root = [1, 2, 3] -> 2 (2 and 3) Example 2: root = [1, 2] -> 1 Example 3: root = [1] -> 1 (the root is a leaf) Example 4: root = [] -> 0

Trees are shown in level order, with `null` for a missing child. Constraints: 0 <= number of nodes <= 1000, -100 <= Node.val <= 100.
