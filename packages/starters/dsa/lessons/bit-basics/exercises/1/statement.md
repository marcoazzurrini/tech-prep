# Positions of Set Bits (easy)

Given a non-negative integer `n`, return the positions of the bits that are 1 in its binary form. Position 0 is the lowest bit. Return the positions in increasing order.

Example 1: n = 10 -> [1, 3] 10 is 1010 in binary. Example 2: n = 1 -> [0] Example 3: n = 0 -> []

Constraints: 0 <= n <= 2^31 - 1.
