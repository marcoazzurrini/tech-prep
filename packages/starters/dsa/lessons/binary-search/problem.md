# Search High to Low (easy)

The array `scores` holds different integers, sorted from **largest to smallest**. Return the index of `target` in `scores`. If `target` is not in the array, return `-1`. Your solution must run in O(log n) time.

Example 1: scores = [9, 7, 5, 3, 1], target = 7 -> 1 Example 2: scores = [9, 7, 5, 3, 1], target = 4 -> -1 Example 3: scores = [], target = 1 -> -1

Constraints: 0 <= len(scores) <= 10^4, -10^4 <= scores[i], target <= 10^4. All values in `scores` are different.
