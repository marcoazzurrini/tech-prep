# Count Distinct Prefixes (easy)

You get a list of `words`. A prefix of a word is its first 1 or more letters. The whole word is also a prefix. Count how many different prefixes the words have in total. Build a trie to count them.

Example 1: words = ["tea", "ten"] -> 4 ("t", "te", "tea", "ten") Example 2: words = ["a", "a"] -> 1 Example 3: words = [] -> 0

Constraints: 0 <= len(words) <= 100, 1 <= len(words[i]) <= 20, lowercase English letters.
