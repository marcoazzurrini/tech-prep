# First Repeated Value (easy)

`nums` has `n` numbers, and each number is from `1` to `n`. Read the array from left to right. Return the first value that you meet for the second time. Return `-1` if no value repeats.

Use no set and no second array. You may change `nums`.

Example 1: nums = [2, 1, 3, 1, 2] -> 1 (the second 1 comes before the second 2) Example 2: nums = [1, 2, 3] -> -1 Example 3: nums = [3, 3, 3] -> 3

Constraints: 1 <= n <= 1000, 1 <= nums[i] <= n.
