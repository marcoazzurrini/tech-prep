# Longest Substring With a Letter Limit (easy)

Given a string `s` and a number `limit`, find the longest substring in which no letter appears more than `limit` times. Return its length.

Example 1: s = "aabbb", limit = 2 -> 4 ("aabb") Example 2: s = "aaaa", limit = 1 -> 1 Example 3: s = "abab", limit = 1 -> 2

Constraints: 1 <= len(s) <= 10^5, 1 <= limit <= 10^5, lowercase English letters.
