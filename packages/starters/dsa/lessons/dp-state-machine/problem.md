# Work Days with Rest (easy)

`pay[i]` is the money you earn if you work on day `i`. Each day you either work or rest. You may not work more than two days in a row.

Return the most money you can earn.

Example 1: pay = [3, 4, 5] -> 9 (rest on day 0, work on days 1 and 2) Example 2: pay = [5, 5] -> 10 (two days in a row are allowed) Example 3: pay = [10, 1, 10] -> 20 (rest on day 1)

Constraints: 1 <= len(pay) <= 1000, 0 <= pay[i] <= 1000.
