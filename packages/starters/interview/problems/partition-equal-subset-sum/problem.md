# Partition Equal Subset Sum (medium)

Given an array `nums` of positive integers, return `true` if you can split it into two groups with the same sum. Every number goes into exactly one group. Otherwise return `false`.

Example 1: nums = [1, 5, 11, 5]  ->  true
  The groups are [1, 5, 5] and [11].
Example 2: nums = [1, 2, 3, 5]  ->  false

Constraints: 1 <= len(nums) <= 200, 1 <= nums[i] <= 100.
