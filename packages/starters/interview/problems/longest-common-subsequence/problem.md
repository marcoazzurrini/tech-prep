# Longest Common Subsequence (medium)

Given two strings `text1` and `text2`, return the length of the longest sequence of characters that appears in both, in the same order but not necessarily contiguously. Return 0 if they share no characters.

Example 1: text1 = "abcde", text2 = "ace"  ->  3  ("ace")
Example 2: text1 = "abc", text2 = "abc"  ->  3
Example 3: text1 = "abc", text2 = "def"  ->  0

Constraints: 1 <= len(text1), len(text2) <= 1000, both contain only lowercase English letters.
