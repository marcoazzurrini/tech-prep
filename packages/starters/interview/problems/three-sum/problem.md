# 3Sum (medium)

Given an integer array `nums`, return every distinct triplet `[a, b, c]` of values taken from three different positions where `a + b + c == 0`. The result must not contain duplicate triplets. Order of triplets, and of values inside a triplet, does not matter.

Example 1: nums = [-1, 0, 1, 2, -1, -4]  ->  [[-1, -1, 2], [-1, 0, 1]]
Example 2: nums = [0, 1, 1]  ->  []
Example 3: nums = [0, 0, 0]  ->  [[0, 0, 0]]

Constraints: 3 <= len(nums) <= 3000.
