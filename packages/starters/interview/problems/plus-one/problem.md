# Plus One (easy)

`digits` holds the digits of a non-negative integer, with the most significant digit first. Add one to the integer and return the digits of the result.

Example 1: digits = [1, 2, 3]  ->  [1, 2, 4]
Example 2: digits = [1, 9, 9]  ->  [2, 0, 0]
Example 3: digits = [9]  ->  [1, 0]

Constraints: 1 <= len(digits) <= 100, 0 <= digits[i] <= 9. There is no leading zero, except for the number 0 itself.
