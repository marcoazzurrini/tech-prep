# Climbing Stairs (easy)

A staircase has `n` steps. Each move climbs either 1 or 2 steps. Return how many distinct sequences of moves take you from the bottom to exactly the top.

Example 1: n = 2  ->  2  (1+1, 2)
Example 2: n = 3  ->  3  (1+1+1, 1+2, 2+1)
Example 3: n = 5  ->  8

Constraints: 1 <= n <= 45.
