# Binary Search (easy)

The array `nums` holds different integers, sorted from smallest to largest. Return the index of `target` in `nums`. If `target` is not in the array, return `-1`. Your solution must run in O(log n) time.

Example 1: nums = [-1, 0, 3, 5, 9, 12], target = 9  ->  4
Example 2: nums = [-1, 0, 3, 5, 9, 12], target = 2  ->  -1

Constraints: 1 <= len(nums) <= 10^4, -10^4 <= nums[i], target <= 10^4. All values in `nums` are different.
