# Counting Bits (easy)

Given an integer `n`, return a list `ans` of length `n + 1` where `ans[i]` is the number of 1 bits in the binary form of `i`, for every `i` from 0 to `n`.

Example 1: n = 2  ->  [0, 1, 1]
Example 2: n = 5  ->  [0, 1, 1, 2, 1, 2]

Constraints: 0 <= n <= 10^5.
Follow-up: can you do it in O(n) total, reusing answers you already computed?
