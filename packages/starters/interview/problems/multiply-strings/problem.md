# Multiply Strings (medium)

`num1` and `num2` are non-negative integers written as strings. Return their product, also as a string.

The numbers can be far too large for a normal integer. Do not convert the whole strings to numbers, and do not use a big-integer library. Work digit by digit.

Example 1: num1 = "2", num2 = "3"  ->  "6"
Example 2: num1 = "123", num2 = "456"  ->  "56088"
Example 3: num1 = "0", num2 = "52"  ->  "0"

Constraints: 1 <= len(num1), len(num2) <= 200, digits only. There is no leading zero, except for the number "0" itself.
