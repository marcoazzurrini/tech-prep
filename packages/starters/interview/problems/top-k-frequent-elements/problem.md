# Top K Frequent Elements (medium)

Given an integer array `nums` and an integer `k`, return the `k` most frequent values. The answer is guaranteed to be unique. Return it in any order.

Example 1: nums = [1, 1, 1, 2, 2, 3], k = 2  ->  [1, 2]
Example 2: nums = [1], k = 1  ->  [1]

Constraints: 1 <= len(nums) <= 10^5, 1 <= k <= number of distinct values.
Follow-up: can you do better than O(n log n)?
