# Subsets (medium)

Given a list `nums` of distinct integers, return every subset of `nums`. A subset keeps some of the numbers and leaves out the rest. The empty list and the full list are both subsets. Return the subsets in any order. The numbers inside a subset may also be in any order.

Example 1: nums = [1, 2, 3]  ->  [[], [1], [2], [3], [1, 2], [1, 3], [2, 3], [1, 2, 3]]
Example 2: nums = [0]  ->  [[], [0]]
Example 3: nums = []  ->  [[]]

Constraints: 0 <= len(nums) <= 10, -10 <= nums[i] <= 10, all numbers are distinct.
