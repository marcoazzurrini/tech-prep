# Palindromic Substrings (medium)

Given a string `s`, count its palindromic substrings: contiguous pieces that read the same in both directions. Substrings at different positions count separately even if their text is identical.

Example 1: s = "abc"  ->  3  ("a", "b", "c")
Example 2: s = "aaa"  ->  6  (three "a", two "aa", one "aaa")
Example 3: s = "abba"  ->  6  ("a", "b", "b", "a", "bb", "abba")

Constraints: 1 <= len(s) <= 1500, s contains only lowercase English letters.
