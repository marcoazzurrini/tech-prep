# Find the Duplicate Number (medium)

The array `nums` holds `n + 1` integers. Every integer is between `1` and `n`. Exactly one value appears more than once. It may appear two times or more. Return that value.

Do not change `nums`. Use only O(1) extra memory.

Example 1: nums = [1, 3, 4, 2, 2]  ->  2
Example 2: nums = [3, 1, 3, 4, 2]  ->  3
Example 3: nums = [2, 2, 2, 2, 2]  ->  2

Constraints: 1 <= n <= 10^5, len(nums) = n + 1, 1 <= nums[i] <= n, one value repeats and every other value appears at most once.
Follow-up: can you do it in O(n) time?
