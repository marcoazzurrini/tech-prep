# House Robber (medium)

Houses stand in a row and `nums[i]` is the cash in house `i`. You may take cash from any set of houses as long as no two chosen houses are next to each other. Return the largest total you can collect.

Example 1: nums = [1, 2, 3, 1]  ->  4  (houses 0 and 2)
Example 2: nums = [2, 7, 9, 3, 1]  ->  12  (houses 0, 2 and 4)
Example 3: nums = [2, 1, 1, 2]  ->  4  (houses 0 and 3)

Constraints: 1 <= len(nums) <= 3000, 0 <= nums[i] <= 400.
