# Group Anagrams (medium)

Given a list of strings `strs`, group the strings that are anagrams of each other. Return the groups in any order; strings inside a group may also be in any order.

Example 1: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
           ->  [["bat"], ["nat", "tan"], ["ate", "eat", "tea"]]
Example 2: strs = [""]  ->  [[""]]

Constraints: 1 <= len(strs) <= 10^4, 0 <= len(strs[i]) <= 100, lowercase English letters.
