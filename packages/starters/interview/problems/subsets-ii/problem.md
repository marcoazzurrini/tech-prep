# Subsets II (medium)

Given a list `nums` of integers that may contain duplicates, return every distinct subset of `nums`. Two subsets are the same if they hold the same numbers the same number of times. Each distinct subset must appear once. Return the subsets in any order. The numbers inside a subset may also be in any order.

Example 1: nums = [1, 2, 2]  ->  [[], [1], [2], [1, 2], [2, 2], [1, 2, 2]]
Example 2: nums = [0]  ->  [[], [0]]
Example 3: nums = [1, 1]  ->  [[], [1], [1, 1]]

Constraints: 0 <= len(nums) <= 10, -10 <= nums[i] <= 10.
