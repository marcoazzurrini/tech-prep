# Missing Number (easy)

The array `nums` holds `n` distinct numbers taken from the range `0..n` (inclusive), so exactly one number of that range is absent. Return it.

Example 1: nums = [3, 0, 1]  ->  2
Example 2: nums = [0, 1]  ->  2 (the range is 0..2)
Example 3: nums = [9, 6, 4, 2, 3, 5, 7, 0, 1]  ->  8

Constraints: 1 <= n <= 10^4, all values distinct.
Follow-up: can you use O(1) extra space and O(n) time?
