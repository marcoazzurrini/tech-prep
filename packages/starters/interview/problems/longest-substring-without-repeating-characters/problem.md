# Longest Substring Without Repeating Characters (medium)

Given a string `s`, return the length of the longest substring (contiguous) that contains no repeated character.

Example 1: s = "abcabcbb"  ->  3   ("abc")
Example 2: s = "bbbbb"  ->  1
Example 3: s = "pwwkew"  ->  3   ("wke"; "pwke" is a subsequence, not a substring)

Constraints: 0 <= len(s) <= 5 * 10^4; letters, digits, symbols and spaces.
