# Unique Paths (medium)

A robot starts in the top-left cell of an `m` x `n` grid and wants to reach the bottom-right cell. Each move goes one cell right or one cell down. Return the number of distinct paths.

Example 1: m = 3, n = 7  ->  28
Example 2: m = 3, n = 2  ->  3  (right-down-down, down-right-down, down-down-right)
Example 3: m = 1, n = 1  ->  1

Constraints: 1 <= m, n <= 100. The answer is at most 2 * 10^9.
