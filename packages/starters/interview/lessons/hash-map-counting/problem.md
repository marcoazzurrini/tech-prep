# Values Seen Exactly Twice (easy)

Given an integer array `nums`, return how many different values appear exactly two times in it.

Example 1: nums = [1, 2, 2, 3, 3, 3] -> 1 Only `2` appears exactly twice. Example 2: nums = [4, 4, 5, 5] -> 2 Example 3: nums = [] -> 0

Constraints: 0 <= len(nums) <= 10^4, -10^9 <= nums[i] <= 10^9.
