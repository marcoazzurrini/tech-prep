# Count Reachable Totals (easy)

Given an array `nums` of positive integers, pick any of the numbers and add them up. Each number can be picked at most once. Picking nothing gives the total `0`.

Return how many different totals you can make.

Example 1: nums = [1, 2] -> 4 The totals are 0, 1, 2 and 3. Example 2: nums = [2, 2] -> 3 The totals are 0, 2 and 4. Example 3: nums = [] -> 1

Constraints: 0 <= len(nums) <= 50, 1 <= nums[i] <= 100.
