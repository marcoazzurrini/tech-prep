# Is It a Consecutive Run (easy)

Given an integer array `nums`, return `true` if its values can be put in an order where each value is exactly 1 more than the value before it. Otherwise return `false`.

Example 1: nums = [3, 1, 2] -> true (1, 2, 3) Example 2: nums = [1, 3, 2, 5] -> false (4 is missing) Example 3: nums = [2, 2, 3] -> false (2 appears twice)

Constraints: 1 <= len(nums) <= 1000, -10^4 <= nums[i] <= 10^4.
