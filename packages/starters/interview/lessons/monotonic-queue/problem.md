# Largest Window Minimum (easy)

A window of `k` elements slides over `nums`. Each window has a smallest value. Return the largest of these smallest values.

Example 1: nums = [3, 1, 4, 5, 2], k = 2 -> 4 (the window [4, 5] has minimum 4) Example 2: nums = [1, 2, 3], k = 3 -> 1 Example 3: nums = [6, 5, 4, 3], k = 2 -> 5

Constraints: 1 <= k <= len(nums) <= 10^5, -10^4 <= nums[i] <= 10^4.
