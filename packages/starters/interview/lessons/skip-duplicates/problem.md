# Top Distinct Scores (easy)

Given a list of `scores` and a number `k`, return the `k` highest distinct scores, from highest to lowest. A score that appears many times counts once. If there are fewer than `k` distinct scores, return all of them.

Example 1: scores = [50, 80, 80, 70], k = 2 -> [80, 70] Example 2: scores = [5, 5, 5], k = 2 -> [5] Example 3: scores = [1, 2, 3], k = 3 -> [3, 2, 1]

Constraints: 1 <= len(scores) <= 1000, 1 <= k <= 1000, -10^4 <= scores[i] <= 10^4.
