# Count in Range (easy)

The array `nums` holds integers sorted from smallest to largest. Values may repeat. Return how many values lie between `low` and `high`, with both ends included. Your solution must run in O(log n) time.

Example 1: nums = [1, 3, 3, 5, 8], low = 3, high = 5 -> 3 The values 3, 3 and 5 are in the range. Example 2: nums = [1, 5, 9], low = 6, high = 8 -> 0 Example 3: nums = [2, 2, 2, 2], low = 2, high = 2 -> 4

Constraints: 0 <= len(nums) <= 10^4, -10^4 <= nums[i] <= 10^4, -10^4 <= low <= high <= 10^4.
