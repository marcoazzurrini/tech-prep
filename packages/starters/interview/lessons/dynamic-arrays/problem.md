# First and Last Letters (easy)

Given a list `words`, return a new list of the same length. For each word, it holds a string of two letters: the first letter of the word, then its last letter. A word of one letter gives that letter twice.

Example 1: words = ["apple", "kiwi"] -> ["ae", "ki"] Example 2: words = ["a"] -> ["aa"] Example 3: words = [] -> []

Constraints: 0 <= len(words) <= 1000, 1 <= len(words[i]) <= 20, lowercase English letters.
