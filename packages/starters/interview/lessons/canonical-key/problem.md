# Group Words by Length (easy)

Given a list of words, group the words that have the same length. Return the groups in any order; words inside a group may also be in any order.

Example 1: words = ["a", "bb", "cc"]  ->  [["a"], ["bb", "cc"]]
Example 2: words = ["hi"]  ->  [["hi"]]
Example 3: words = []  ->  []

Constraints: 0 <= len(words) <= 1000, 1 <= len(words[i]) <= 20, lowercase English letters.
