# Most of One Letter in a Window (easy)

Given a string `s`, a window length `k` and a single character `letter`, look at every substring of `s` with length `k`. Return the largest number of times `letter` appears in one of them.

Example 1: s = "banana", k = 3, letter = "a" -> 2 ("ana" has two) Example 2: s = "aaaa", k = 2, letter = "a" -> 2 Example 3: s = "abc", k = 3, letter = "z" -> 0

Constraints: 1 <= k <= len(s) <= 10^5, `letter` is one character.
