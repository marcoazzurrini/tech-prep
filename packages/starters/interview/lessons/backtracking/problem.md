# List the Ways to Climb (easy)

You climb `total` stairs. Each move goes up `1` stair or `2` stairs. Return every list of moves that climbs exactly `total` stairs. The order of the moves matters: `[1, 2]` and `[2, 1]` are different. Return the lists in any order.

Example 1: total = 3  ->  [[1, 1, 1], [1, 2], [2, 1]]
Example 2: total = 1  ->  [[1]]
Example 3: total = 2  ->  [[1, 1], [2]]

Constraints: 1 <= total <= 10.
