# Last Even Value (easy)

You get the `head` of a linked list. Return the value of the last node that holds an even number. Return `-1` if no node holds an even number.

Example 1: head = [3, 4, 7, 6, 1] -> 6 Example 2: head = [1, 3, 5] -> -1 Example 3: head = [] -> -1

Constraints: 0 <= number of nodes <= 100, 0 <= Node.val <= 1000.
