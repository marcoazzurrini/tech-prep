# Reverse the First K Nodes (easy)

You get the `head` of a linked list and a number `k`. Reverse the first `k` nodes. Leave the other nodes in their order, after the reversed part. Return the new head.

Example 1: head = [1, 2, 3, 4, 5], k = 3 -> [3, 2, 1, 4, 5] Example 2: head = [1, 2], k = 2 -> [2, 1] Example 3: head = [7, 8, 9], k = 1 -> [7, 8, 9]

Constraints: 1 <= k <= number of nodes <= 100, 0 <= Node.val <= 1000.
