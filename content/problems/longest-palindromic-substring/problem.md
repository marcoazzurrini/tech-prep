# Longest Palindromic Substring (medium)

Given a string `s`, return a longest contiguous substring of `s` that reads the same forwards and backwards. If several substrings tie for the longest length, return any one of them.

Example 1: s = "babad"  ->  "bab"  ("aba" is also accepted)
Example 2: s = "cbbd"  ->  "bb"
Example 3: s = "ac"  ->  "a"  ("c" is also accepted)

Constraints: 1 <= len(s) <= 2000, s contains only lowercase English letters.
Follow-up: can you do it in O(n^2) time with O(1) extra space?
