# Invert Binary Tree (easy)

Given the `root` of a binary tree, mirror it: swap the left and right child of every node. Return the root.

Example 1: root = [4, 2, 7, 1, 3, 6, 9]  ->  [4, 7, 2, 9, 6, 3, 1]
Example 2: root = [2, 1, 3]  ->  [2, 3, 1]
Example 3: root = []  ->  []

Trees are shown in level order, with `null` for a missing child.
Constraints: 0 <= number of nodes <= 100, -100 <= Node.val <= 100.
