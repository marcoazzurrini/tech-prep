# Valid Anagram (easy)

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`: it uses exactly the same characters with the same counts, possibly in a different order.

Example 1: s = "anagram", t = "nagaram"  ->  true
Example 2: s = "rat", t = "car"  ->  false

Constraints: 0 <= len(s), len(t) <= 5 * 10^4, lowercase English letters.
