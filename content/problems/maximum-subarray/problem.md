# Maximum Subarray (medium)

Given an integer array `nums`, find the non-empty contiguous subarray with the largest sum and return that sum.

Example 1: nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]  ->  6  (subarray [4, -1, 2, 1])
Example 2: nums = [1]  ->  1
Example 3: nums = [5, 4, -1, 7, 8]  ->  23  (the whole array)

Constraints: 1 <= len(nums) <= 10^5, -10^4 <= nums[i] <= 10^4.
Follow-up: can you do it in O(n) time?
