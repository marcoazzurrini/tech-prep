# Maximum Product Subarray (medium)

Given an integer array `nums`, find the non-empty contiguous subarray whose elements multiply to the largest value, and return that product.

Example 1: nums = [2, 3, -2, 4]  ->  6  (subarray [2, 3])
Example 2: nums = [-2, 0, -1]  ->  0
Example 3: nums = [-2, 3, -4]  ->  24  (the whole array)

Constraints: 1 <= len(nums) <= 5000, -10 <= nums[i] <= 10. Every subarray product fits in a 32-bit integer.
