# Number of Connected Components in an Undirected Graph (medium)

You are given `n` nodes labelled `0` to `n - 1` and a list of undirected `edges`. Return the number of connected components (a node with no edges is a component on its own).

Example 1: n = 5, edges = [[0, 1], [1, 2], [3, 4]]  ->  2
Example 2: n = 5, edges = [[0, 1], [1, 2], [2, 3], [3, 4]]  ->  1

Constraints: 1 <= n <= 2000, 0 <= len(edges) <= 5000, no self-loops or repeated edges.
