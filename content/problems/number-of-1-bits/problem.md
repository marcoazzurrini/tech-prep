# Number of 1 Bits (easy)

Given an unsigned 32-bit integer `n`, return how many of its bits are set to 1 (its Hamming weight).

Example 1: n = 11  ->  3 (binary 1011)
Example 2: n = 128  ->  1 (binary 10000000)
Example 3: n = 4294967293  ->  31 (binary 11111111111111111111111111111101)

Constraints: 0 <= n <= 2^32 - 1.
Follow-up: can you loop once per set bit instead of once per bit?
