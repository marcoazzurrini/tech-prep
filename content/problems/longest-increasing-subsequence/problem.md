# Longest Increasing Subsequence (medium)

Given an integer array `nums`, return the length of its longest strictly increasing subsequence. A subsequence keeps the original order but may skip elements.

Example 1: nums = [10, 9, 2, 5, 3, 7, 101, 18]  ->  4  (e.g. [2, 3, 7, 101])
Example 2: nums = [0, 1, 0, 3, 2, 3]  ->  4  ([0, 1, 2, 3])
Example 3: nums = [7, 7, 7, 7]  ->  1

Constraints: 1 <= len(nums) <= 2500, -10^4 <= nums[i] <= 10^4.
Follow-up: can you do it in O(n log n) time?
