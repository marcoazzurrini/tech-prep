# Rotate Image (medium)

You are given an `n x n` matrix. Rotate it 90 degrees clockwise in place: modify `matrix` directly instead of building a new one. The function returns nothing; the matrix itself is checked.

Example 1: matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]  ->  [[7, 4, 1], [8, 5, 2], [9, 6, 3]]
Example 2: matrix = [[5, 1, 9, 11], [2, 4, 8, 10], [13, 3, 6, 7], [15, 14, 12, 16]]  ->  [[15, 13, 2, 5], [14, 3, 4, 1], [12, 6, 8, 9], [16, 7, 10, 11]]

Constraints: 1 <= n <= 20, -1000 <= matrix[i][j] <= 1000.
